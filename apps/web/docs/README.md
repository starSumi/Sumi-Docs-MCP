# Maintainer documentation map

This directory describes how the documentation application is changed and
released. Product pages and the machine-readable showcase corpus are authored
under the workspace root `docs/` and reviewed through
`src/content-catalog.ts`.

| Document                          | Purpose                                                              |
| --------------------------------- | -------------------------------------------------------------------- |
| [Content model](content-model.md) | Content ownership, localization, routes, and projection workflow     |
| [Deployment](deployment.md)       | Immutable site candidates, human acceptance, promotion, and rollback |

The root [README](../README.md) is the development entry point.
[CONTRIBUTING](../CONTRIBUTING.md), [SECURITY](../SECURITY.md), and
[CHANGELOG](../CHANGELOG.md) own the standard repository contracts.
