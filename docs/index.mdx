## Two views, one source

### For people

Browse rendered pages with navigation, accessible code blocks, and local search.

### For MCP clients

Load the strict `_mcp/sumi-docs-manifest.json` projection through the existing
read-only tools.

### One trust boundary

Reviewed Markdown and MDX are rendered by Astro. The MCP server parses the
published source as data and never executes it.
