# Historical project reports

Files in this directory are condensed summaries of early implementation phases.
They are superseded and are not evidence of the current build, test count,
dependency versions, supported transports, or release status. The verbose
generated phase logs were intentionally excluded from the authoritative public
repository because they contained stale claims and fictional sign-offs.

Current behavior is documented by the root README, the active files under
`docs/`, source code, and automated tests.

| File | Original purpose |
| --- | --- |
| `phase-01-scaffold.md` | initial scaffold completion note |
| `phase-01-validation.md` | initial scaffold validation note |
| `phase-02-implementation.md` | parser and VFS implementation note |
| `phase-02-verification.md` | parser and VFS verification note |
