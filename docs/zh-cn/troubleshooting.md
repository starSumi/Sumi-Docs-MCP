## 可执行文件显示帮助后退出

它是命令行服务，不是桌面应用。请由 MCP 客户端使用 `serve <docs-source>`
启动，或在终端运行文档中的命令。无参数双击时显示帮助并以代码 0 退出是预期行为。

## 进程看起来没有输出

stdio 服务会等待标准输入中的 JSON-RPC。启动后保持安静是正常的。协议输出使用
stdout，诊断使用 stderr；不要把普通日志写入 stdout。

## 结果里没有可点击 URL

传入 HTTP 或 HTTPS `--base-url`。它把机器文档路径映射成人可以打开的页面，
不会托管文件，也不会改变 MCP 传输方式。

## 远程文档集加载失败

源地址应指向包含 `sumi-docs-manifest.json` 的目录，通常是已部署站点的
`/_mcp/` 路径。加载器接受 HTTPS，并允许回环地址 HTTP 用于本地测试；它会拒绝
凭据、重定向、路径穿越、未知清单字段、超限响应和非 JSON OpenAPI 源。

## 文档修改后没有更新

文档集是进程内快照。修改本地文件或发布新的远程文档集后，请重启 MCP 进程。

先运行 `doctor --json`。路径默认显示为相对值或占位符；只有本机交互排查时才使用
`--show-paths`，且不要发布其输出。客户端错误与 stderr 诊断都不会包含调用栈或 URL
凭据。
